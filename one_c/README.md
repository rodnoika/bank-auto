# Подключение к 1С:Бухгалтерии для Казахстана 3.0

Модуль `BankHubClient.bsl` выполняется на сервере 1С, поэтому один и тот же код
работает в толстом, тонком и веб-клиенте. Разница только в адресе сервиса:

- файловая база на том же компьютере: `http://127.0.0.1:8000`;
- серверная или облачная база: публичный HTTPS-адрес сервиса, доступный серверу 1С.

## Установка

1. В конфигураторе создайте расширение `BankHub` без изменения основной конфигурации.
2. Добавьте общий модуль `BankHubClient`: серверный, с флагом «Вызов сервера».
3. Вставьте код из `BankHubClient.bsl`.
4. Выполните `BankHubClient.ПроверитьНастройку()`. Функция должна вернуть имена
   входящего и исходящего банковских документов и два значения `Истина` для справочников.
5. Добавьте команду формы или регламентное задание, которое вызывает:

```bsl
BankHubClient.ЗагрузитьПодтвержденныеОперации(
    "http://127.0.0.1:8000",
    "значение_APP_API_KEY");
```

Для веб-клиента вызов должен идти из серверной процедуры расширения. Не размещайте
API-ключ в клиентском коде формы.

## Что создается

- `incoming` — платежный ордер поступления или входящее платежное поручение;
- `outgoing` — платежный ордер списания или исходящее платежное поручение;
- документ записывается непроведенным, чтобы бухгалтер мог проверить счета учета,
  договор и вид операции перед проведением;
- операция помечается `exported` только после успешной записи документа;
- в комментарий записывается маркер `BankHub:<id>`, поэтому повторный запуск не
  создает дубль, даже если связь оборвалась после записи в 1С.

Банковский счет организации ищется по IBAN, контрагент — по БИН/ИИН. Если их нет
в базе 1С, документ не создается, а причина попадает в журнал регистрации с событием
`ВыпискиВ1С`.
