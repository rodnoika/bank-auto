# Выписки → 1С

Узкий MVP для бухгалтеров: загрузить PDF-выписку, проверить распознанные операции и передать подтверждённые документы в 1С.

## Как работает

1. Бухгалтер скачивает PDF-выписку из интернет-банка.
2. Загружает её в веб-интерфейс.
3. Сервис извлекает операции и ставит их в статус `review` («На проверке»).
4. Бухгалтер исправляет реквизиты, при необходимости просит GPT‑4o привести текст назначения платежа в порядок и подтверждает операции.
5. 1С забирает только статус `ready` и после успешного создания документа отмечает запись как `exported`.

Повторная загрузка той же операции не создаёт дубль. PDF обрабатывается в памяти и не сохраняется на диск. GPT‑4o вызывается только вручную для одной операции; вся выписка в OpenAI не отправляется.

## Запуск

```bash
copy .env.example .env
docker compose up --build
```

На Linux/macOS используйте `cp .env.example .env`.

- Next.js интерфейс: <http://localhost:3000>
- FastAPI и Swagger: <http://localhost:8000/docs>

Для действий в интерфейсе введите значение `APP_API_KEY`. Чтобы включить ИИ-помощника, добавьте в `.env`:

```env
OPENAI_API_KEY=ваш_ключ
OPENAI_MODEL=gpt-4o
```

Без ключа OpenAI загрузка, редактирование, дедупликация и экспорт в 1С продолжают работать.

## Деплой на Vercel

Vercel-версия использует два проекта из одного репозитория: FastAPI из корня и
Next.js из каталога `web`. В production данные хранятся в PostgreSQL через
`DATABASE_URL`; локальная разработка продолжает использовать SQLite.

Пошаговая настройка PostgreSQL, переменных окружения, двух Vercel Project и адреса
для 1С описана в [DEPLOY_VERCEL.md](DEPLOY_VERCEL.md). Из-за лимита Vercel Function
production-загрузка ограничена PDF размером до 4 МБ.

## Разработка интерфейса

Интерфейс находится в `web/` и использует Next.js App Router, React и TypeScript. В режиме разработки Next.js проксирует `/api/*` на FastAPI, поэтому CORS не нужен.

На Windows оба сервиса можно запустить одной командой:

```powershell
powershell -ExecutionPolicy Bypass -File .\start-local.ps1
```

Окно должно оставаться открытым, пока используется приложение. Если закрыть процесс Next.js, Chrome может показать сохранённую offline-страницу другого приложения, которое раньше работало на `localhost:3000`.

Либо в одном терминале запустите backend:

```bash
uvicorn app.main:app --reload --port 8000 --env-file .env
```

Во втором терминале:

```bash
cd web
npm install
npm run dev
```

По умолчанию backend доступен по `http://localhost:8000`. Другой адрес можно задать переменной `BACKEND_URL` перед запуском или сборкой Next.js.

## API для 1С

- `GET /api/v1/transactions/export?status=ready` — получить подтверждённые операции.
- `POST /api/v1/transactions/{id}/mark-exported` — подтвердить успешное создание документа в 1С.

Оба запроса требуют заголовок `X-API-Key`.

Полезные endpoint-ы интерфейса:

- `POST /api/v1/pdf` — загрузить PDF (`multipart/form-data`, поле `file`).
- `PATCH /api/v1/transactions/{id}` — исправить поля операции на проверке.
- `POST /api/v1/transactions/{id}/approve` — подтвердить одну операцию.
- `POST /api/v1/transactions/approve` — подтвердить массив `{"ids": [1, 2]}`.
- `POST /api/v1/transactions/{id}/ai-text` — получить подсказку GPT‑4o по тексту операции.
- `GET /health` — состояние сервиса и ИИ.

## Банки и точность

Детектор знает Kaspi Business, Halyk, Forte, BCC, Freedom, Bereke, Alatau City Bank и Eurasian Bank. Сам парсер использует текстовый слой PDF и общие признаки даты, суммы, БИН/ИИН, IBAN, КНП и КБе. Сканированные PDF без текстового слоя пока не поддерживаются.

Разметка банков меняется, поэтому для производственной точности нужны обезличенные примеры каждого фактического формата выписки. Добавлять прямые Bank API в этот MVP не требуется: сначала проверяем ценность короткого пути PDF → проверка → 1С.

```bash
python -m unittest discover -s tests -v

```

Готовый общий модуль для «Бухгалтерии для Казахстана», редакция 3.0, находится в
`one_c/BankHubClient.bsl`. Он динамически определяет стандартные платежные ордера или
платежные поручения, ищет банковский счет организации по IBAN и контрагента по БИН/ИИН,
создает непроведенный документ и только после успешной записи отмечает операцию как
выгруженную. Инструкция по установке в расширение 1С — в `one_c/README.md`.
